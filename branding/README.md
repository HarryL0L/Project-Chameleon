# Project Chameleon logo

A chameleon (Android green → blue → violet) wrapped around a
Wayland-style "W" disc: the Android app holding a Wayland desktop.

- `logo.svg`: master (transparent background), generated by `make_logo.py`
- `logo-1024.png`: 1024 px export
- `preview-sizes.png`: 192 / 96 / 48 px in a circular mask, dark and light

The "W" disc is a stylised nod to Wayland, not the official Wayland logo.
